### 42쌍을 "사이 행이 무엇인가"로 분류 (매출 중앙값 대비 배율 기준)

```
값전무(모든 재무칸 None)   21쌍   ← 유령행, 건너뛴 분기 아님
연간(TTM)행 = 매출 2.5배↑  14쌍   ← 예: ETN 23.2B (분기는 ~6.0B)
스케일이상                  6쌍
진짜 분기 가능성 있음        1쌍   ← GE 2024-04-23→2024-07-23, 사이 '24 Q2' 매출 16.1B
```

**정직한 결론: 사고 7 의 "사이 분기를 건너뛴 가짜 델타"는 42쌍이 아니라 실질 1~7쌍입니다.**
나머지는 파서가 만든 유령행·연간누계행이 사이에 낀 것으로, 델타 자체는 옳습니다.
다만 그 유령행들이 데이터에 남아 있는 것 자체는 별개 문제입니다(축 1~4 소관).

예시 (실행 출력 그대로):
