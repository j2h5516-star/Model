## 1. 주도 판정은 무엇으로 결정되는가 (z10.py 실측)

주도점수 = 완성밀도 × 델타동반 / 100. 두 재료의 몫을 실제로 갈라 봤다.

```
묶음-주 3388
  가격조건(완성>=3 & 밀도>=30) 통과      1408
  델타동반 판단불가                       2113
  델타동반 <50 탈락                        394
  최종 조건충족                            772
→ 가격조건 통과분 중 델타 때문에 탈락/판단불가: 636 = 45.2%
```

완성 사건의 델타를 전부 상승으로 강제하면 **주도가 110/210주(52.4%)에서 달라진다.**
전부 판단불가로 두면 199/210주(94.8%)에서 주도가 사라진다.

> **즉 주도 판정은 가격 절반 · 이익 델타 절반이다.**
> 가격은 깨끗하다(축3). 델타는 깨끗하지 않다(축1·4·5·7).

`sector_model.py` 에 잣대 칸(adj_eps/gaap_eps/adjusted_ebitda) 등장 0회 —
**완성수는 순수 가격 산물**이라는 점은 확인했다. 오염 경로는 델타 한 곳뿐이다.

## 2. 가장 큰 문제 — 장치가 불안정하다 (z6.py, 대조 실험)

오염을 고치는 문제가 아니다. **깨끗한 값을 무작위로 6% 지워도 답이 바뀐다.**

실제로 쓰이는 잣대 칸 2514개 중 **무작위 152개(6.0%)** 를 지우고 8번 반복:

```
시행1 54/210(25.7%)   시행5 79/210(37.6%)
시행2 13/210( 6.2%)   시행6 41/210(19.5%)
시행3 48/210(22.9%)   시행7 77/210(36.7%)
시행4 54/210(25.7%)   시행8 32/210(15.2%)
중앙값 25.7% | 범위 6.2~37.6%
```

마지막 주 주도도 시행4·7 에서는 '의약·의료' 로 바뀌었다.

**왜 이렇게 약한가** (z8.py):

```
주당 '조건충족(주도 자격)' 묶음 수: 중앙값 3.0   (0개인 주도 20주)
도전자 2개 이상인 주 169/210
1위-2위 주도점수 격차: 중앙값 7.9 | 5점 이내 61주 | 완전 동점 15주
주도 주의 완성수 중앙값 = 3   ← MIN_COMPLETIONS 문턱이 정확히 3
델타동반 값이 있는 주간행 1275/3388 = 37.6%
```

주도는 **평균 3개 후보 중에서, 문턱에 딱 걸친 완성 3건으로, 7.9점 차로** 뽑힌다.
표본이 이 정도로 얇으면 데이터를 다 고쳐도 재현 가능한 답이 안 나온다.

## 3. 델타 오염의 정체 — 무작위 잡음이 아니라 **체계적 파서 결함**

### 3-1. 회계연도 마감 행에 **연간값**이 들어간다 (z13/z14/z15.py) ★ 최대 결함

같은 달에 2년 이상 반복되는 4배 스파이크 = 결산 보도자료에서 분기 열이 아니라
**연간 열**을 집은 지문. 확증 17종목 62행.

산술 검산 (값 vs 직전 4분기 합):

| 종목 | 발표일 | 저장값 | 직전4분기 합 | 차이 |
|---|---|---|---|---|
| QCOM | 2024-11-06 | 10.22 | 9.77 | **+0.45** |
| AXP | 2025-01-24 | 14.01 | 13.59 | **+0.42** |
| FDX | 2024-06-25 | 17.80 | 17.34 | **+0.46** |
| VZ | 2024-01 / 2025-01 / 2026-01 | 4.71 / 4.59 / 4.71 | 정상분기 중앙 1.21 | 4년 연속 1월 |
| GS | 2025-01-15 / 2026-01-15 | 40.54 / 51.32 | 정상분기 중앙 10.76 | 2년 연속 1월 |
| HON | 2023-10 / 2024-10 | 9.10 / 10.15 | 정상분기 중앙 2.55 | 2년 연속 10월 |

차이가 한 분기 성장분(0.42~0.46)에 정확히 떨어진다 = **연간값 확정.**
계절성이 아니다. 같은 회계 위치에서 해마다 반복된다.

**덤으로 발견한 새 값**: FDX 2026-05-13 adj_eps = **68.22**
(직전 4분기 합 18.23의 3.7배 = 연간값의 4배). 어떤 단위로도 설명 불가.
이 값은 기존 감사 어느 축에도 안 적혀 있다.

**왜 치명적인가**: 이 오류는 매년 같은 자리에서 반복돼
① 결산 분기에 가짜 '델타 상승', ② 그 다음 분기에 가짜 '델타 하락' 을 만든다.
델타동반 문턱(50%)을 해마다 두 번씩 흔든다.

### 3-2. 오염이 **주도 경쟁 묶음에 집중**돼 있다 (z11.py)

주도로 등장한 11개 묶음의 오염의심 종목 비율:

```
75.0%  통신·미디어 회선          (3/4)  T VZ TMUS      ← 주도 50주 = 1위
72.7%  반도체 팹 장비·소재        (8/11)
53.8%  산업 설비·자동화·수송      (7/13)
50.0%  교체주기 기업 IT 하드웨어  (4/8)  ← 주도 37주 = 2위
45.0%  기기 OEM 반도체            (9/20) ← 현재 주도
```

**주도 1위 묶음(통신·미디어 회선)은 회원이 4명뿐이고 그중 3명이 오염 의심이다.**
델타동반 분모는 3명만 있으면 성립한다.

### 3-3. 확증 오염만 지웠을 때 (z14.py) — 결정적 반사실

```
확증 62칸(17종목) None 처리
→ 주도 달라진 주 48/210 = 22.9%
→ 전환사건 18 → 16
→ 통신·미디어 회선: 주도 50주 중 32주(64%)를 잃음
→ 그 자리를 금융 중개·자본시장(15) · 교체주기 IT HW(12) · 반도체 팹 장비(10) 가 가져감
```

**주도 1위 묶음의 임기 3분의 2가 파서 결함이 만든 것이었다.**

### 3-4. 정화 강도별 요약

| 정화 수준 | 지운 칸 | 주도 달라진 주 | 마지막 주도 |
|---|---|---|---|
| 최소(산술 100% 확증: JPM 배당 10 + 연간합일치 9 + adj/gaap 20배 2) | 21칸/11종목 | **4/210 = 1.9%** | 기기 OEM 반도체 (불변) |
| 확증(같은 달 2년+ 반복 연간값) | 62칸/17종목 | **48/210 = 22.9%** | 기기 OEM 반도체 (불변) |
| 광범위(중앙값·연간·중복 휴리스틱) | 152칸/71종목 | **92/210 = 43.8%** | 분산형 에너지·전동화 (뒤집힘) |
| **무작위 대조군 152칸** | 152칸 | **중앙값 54/210 = 25.7%** | 대체로 불변 |

**광범위(43.8%)가 무작위 대조군(25.7%)보다 크다** = 오염이 실재한다.
**동시에 대조군이 25.7%나 된다** = 장치가 원래 불안정하다.
둘 다 사실이고, 둘 다 판정을 막는다.

## 6. 고치기 전에는 판정을 믿으면 안 되는 것 (blocking)

1. **회계연도 마감 행 연간값 혼입** — 17종목 62행, 주도 22.9%주 변동,
   1위 묶음 임기 64% 소멸. 매년 반복되는 체계적 파서 결함.

4. **verdict.json 코드 버전 노후** — 화면 주도(데이터센터)와 현재 코드(기기 OEM

6. **분할 미조정 7종목** — NVDA·GOOGL·AVGO·LRCX·SMCI·ANET·WMT.

## 8. 받아들이고 가야 하는 한계

- 주가 데이터는 개발 환경에서 못 받는다 — 가격 검증은 내부 정합성 검사뿐
- raw/ 는 파싱 **실패** 원문 보관소라 성공분 원문 대조는 불가 (159종목 미검증)
- 근사치 100% 종목(META·AMZN·TSLA 등 29개)의 XBRL 근사식 오차는 원문이 없어 확인 못함
- surprise 원장은 4분기만 보관 — DASH·SNAP 같은 장기 정지를 못 잡음
- H5b 앞시기 n=0 (게이지 ON 이 2025·2026 에만 존재) — 원칙4(시간 분할) 미충족
- 국면 19개 · 전환 18건은 표본으로서 원래 작다. 주도섹터 가설이 오래
  "판정 불가" 로 남는 것은 결함이 아니라 사전 등록된 예상이다.

## 9. 고치는 순서

1. **결산 행 연간값 가드** — 잣대값이 같은 회계 월에 반복해서 정상분기 중앙값의
   3~5배면 없음 처리(고치지 말고 버림). 17종목 62행. 효과가 가장 크다.
2. **verdict 에 code_rev(git 해시) 기록** — 화면이 옛 코드 판정을 사실처럼 못 뿌리게.
3. **원문 확증 오염 배제** — JPM 배당 / GNRC 천단위 / UCTT 주식수 / BAC ROTCE / IPGP.
4. **분할 계수 수집** 또는 영구 단차에서 eps_runs 절단.
5. **주도 판정에 안정성 표시 상시 노출** — 무작위 6% 결손 재실행으로
   "이 주의 주도가 흔들리는가"를 함께 적는다. 지금 가장 없는 정보다.
6. 잣대 결손 복구(COP 9 · WDC 6 · OKTA 5 · HUBS 5 · COHR 4)로 표본 두께 확보.
7. 그 다음에야 문턱(MIN_COMPLETIONS·MIN_MEMBERS) 재등록을 논의한다.

## 신뢰도 30/100 의 근거

**올린 이유**: 가격·묶음·인과성이라는 바닥 셋이 독립 검사 20여 개를 전부 통과했다.
주도 판정의 절반(완성수)은 그 위에 서 있다. 모델은 이미 네 개 주도 가설을
전부 "판정 불가" 로 정직하게 적고 있다. 재건축이 아니라 수리로 갈 수 있다.

**낮춘 이유**: 나머지 절반(델타)이 체계적으로 오염돼 있고, 그 오염이 하필
주도를 다투는 묶음에 집중돼 있으며(1위 묶음 4명 중 3명), 확증분만 지워도
1위 묶음 임기의 64%가 사라진다. 그리고 결정적으로 — **깨끗한 값을 무작위로
6%만 지워도 주도가 25.7%주에서 바뀐다.** 데이터를 완벽히 고쳐도 지금 문턱과
표본 두께로는 재현 가능한 주도섹터가 나오지 않는다.

**그래서 답은**: 관찰은 계속하되, **이 데이터로 주도섹터를 확정하지 마라.**
