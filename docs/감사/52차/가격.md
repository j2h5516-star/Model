## 4. 날짜가 하루 밀렸는지 (가장 무서운 오염) — **아니오**

가격표가 하루 밀리면 정배열도 창 수익도 전부 틀립니다. 순수 산술로 잡았습니다:
각 종목의 일간 수익률과 SPY 일간 수익률의 상관을 **같은 날 / 전날 / 다음날**로 재어
같은 날이 가장 높지 않으면 밀림입니다.
```
전날·다음날 상관이 같은 날보다 0.05 이상 높은 종목 : 0개
같은 날 상관 중앙값 0.514 · 최대 0.750 · 0.15 미만 : 0개
가장 낮은 쪽 = VZ 0.155 / JNJ 0.160 / T 0.174 / BMY 0.195 / MRK 0.196
  (전부 저베타 방어주 — 이론과 정확히 일치, 전날·다음날 상관은 −0.06~0.07 로 무의미)
```
