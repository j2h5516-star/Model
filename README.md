## 📱 모바일에서 사용하기 (권장 방법)

스마트폰에는 파이썬을 설치할 수 없지만, **무료 클라우드에 한 번만 올려두면**
그 뒤로는 폰 브라우저에서 주소만 열면 언제 어디서나 대시보드를 볼 수 있습니다.
아래 과정은 전부 **폰에서만** 진행해도 됩니다.

### 최초 1회: Streamlit Community Cloud에 올리기 (약 5분, 무료)

1. 폰 브라우저에서 **[share.streamlit.io](https://share.streamlit.io)** 접속
2. **Continue with GitHub** 를 눌러 GitHub 계정으로 로그인
   (권한 허용 창이 나오면 **Authorize** 를 눌러 승인)
3. **Create app** (또는 **New app**) 버튼 클릭
4. 아래처럼 입력:
   - **Repository**: `j2h5516-star/Model`
   - **Branch**: `main`
   - **Main file path**: `app.py`
5. **Deploy** 버튼을 누르고 1~2분 기다리면 대시보드가 열립니다
6. 주소창의 `https://○○○.streamlit.app` 주소가 내 대시보드 주소입니다 — 즐겨찾기 해두세요!

> ⚠️ 배포 전에 이 코드가 `main` 브랜치에 합쳐져(머지) 있어야 합니다.
> GitHub 앱/웹에서 열려 있는 Pull Request의 **Merge** 버튼을 먼저 눌러 주세요.
> (또는 배포 화면의 Branch 칸에 작업 브랜치 이름을 직접 선택해도 됩니다)

### 홈 화면에 추가하면 진짜 앱처럼 쓸 수 있어요

- **아이폰(Safari)**: 하단 공유 버튼(⬆️) → **홈 화면에 추가**
- **안드로이드(Chrome)**: 오른쪽 위 ⋮ 메뉴 → **홈 화면에 추가**

### 알아두면 좋은 점

- 무료 플랜은 며칠간 접속이 없으면 앱이 잠자기 모드가 됩니다.
  다시 열었을 때 "Yes, get this app back up" 버튼이 보이면 누르고 1분 정도 기다리면 깨어납니다.
- 주가 데이터는 1시간마다 자동 갱신됩니다. 즉시 갱신하려면
  왼쪽 위 **☰ 메뉴(사이드바)** 를 열고 **🔄 데이터 새로고침** 을 누르세요.
- 요약 표는 **좌우로 밀면(스와이프)** 가려진 열을 볼 수 있습니다.
- 코드를 수정해서 GitHub에 올리면 배포된 앱도 자동으로 업데이트됩니다.

## 💻 컴퓨터에서 실행하기 (선택 사항)

### 1단계. 파이썬 설치하기 (이미 있다면 건너뛰기)

1. [python.org/downloads](https://www.python.org/downloads/) 접속
2. 노란색 **Download Python** 버튼 클릭 → 내려받은 파일 실행
3. ⚠️ **중요**: 설치 첫 화면에서 **"Add Python to PATH"** 체크박스에 꼭 체크한 뒤 **Install Now** 클릭
   (이걸 빼먹으면 아래 명령어가 안 먹힙니다. 빼먹었다면 다시 설치하면서 체크해 주세요)

### 2단계. 터미널(명령어 입력 창) 열기

- **Windows**: 키보드에서 `윈도우 키 + R` → `cmd` 입력 → 엔터
- **Mac**: `Command + 스페이스바` → `터미널` 입력 → 엔터

### 3단계. 이 프로젝트 폴더로 이동하기

터미널에 아래처럼 입력하고 엔터를 누릅니다.
(`내려받은폴더경로` 부분은 실제로 이 파일들이 있는 폴더 경로로 바꿔주세요)

```bash
cd 내려받은폴더경로
```

> 💡 **팁**: Windows에서는 폴더를 연 상태에서 주소창에 `cmd` 라고 입력하고
> 엔터를 누르면 그 폴더에서 바로 터미널이 열립니다.

### 4단계. 필요한 프로그램 설치하기 (최초 1회만)

**Windows:**
```bash
pip install -r requirements.txt
```

**Mac:** (`pip` 대신 `pip3` 를 씁니다)
```bash
pip3 install -r requirements.txt
```

설치에 1~2분 정도 걸립니다. 글자가 주르륵 올라가다가 멈추면 완료입니다.

### 5단계. 대시보드 실행하기

```bash
streamlit run app.py
```

(`streamlit` 명령을 찾을 수 없다고 나오면 — Windows: `python -m streamlit run app.py`,
Mac: `python3 -m streamlit run app.py`)

> 💡 처음 실행하면 터미널에 `Email:` 이라고 물어볼 수 있습니다.
> **아무것도 입력하지 말고 엔터만** 누르면 됩니다.

잠시 후 웹 브라우저가 자동으로 열리면서 대시보드가 나타납니다.
(자동으로 안 열리면 브라우저 주소창에 `http://localhost:8501` 을 입력하세요)

### 종료하기

터미널 창에서 `Ctrl + C` 를 누르거나 터미널 창을 닫으면 됩니다.

## 🧭 추세 판정 기준 (5단계)

주봉 종가 기준으로 4주/13주/26주/52주 이동평균선을 계산한 뒤,
아래 순서로 검사해서 먼저 해당되는 상태로 판정합니다.

| 순서 | 상태 | 조건 | 의미 |
|---|---|---|---|
| 1 | 🟢 **완전 정배열** | 주가 > 4주 > 13주 > 26주 > 52주 | 가장 강한 상승 추세 |
| 2 | 🟥 **완전 역배열** | 4주 < 13주 < 26주 < 52주 | 가장 약한 하락 추세 |
| 3 | ⬜ **중립** | 주가가 26주선 ±3% 이내 | 26주선 부근에서 방향 탐색 중 |
| 4 | 🟧 **추세 훼손** | 주가 < 26주선 **또는** 13주선 < 26주선 | 상승 추세가 깨졌다는 경고 |
| 5 | 🟩 **준정배열** | 주가 > 26주 > 52주 (단기 조정 중) | 큰 상승 구조는 유지 |
| 6 | ⬜ **중립(기타)** | 위 어디에도 해당하지 않는 구간 | 추세 전환 초기 등 애매한 상황 |
| - | ❔ **판정 불가** | 52주선을 계산할 데이터 부족 | 상장한 지 1년 미만인 종목 |

**보조 신호**
- **26주선 기울기**: 26주선이 4주 전보다 올라갔으면 상승↗, 내려갔으면 하락↘, 거의 그대로면 횡보→
- **이격도(%)**: 주가가 26주선보다 몇 % 위(+)/아래(−)에 있는지. 이격도가 너무 크면 단기 과열일 수 있습니다.

## ❓ 문제 해결 (FAQ)

**Q. `pip` 또는 `streamlit` 명령어를 찾을 수 없다고 나와요.**
→ (Windows) 파이썬 설치 시 "Add Python to PATH"를 체크하지 않은 경우입니다. 파이썬을 다시 설치하면서 체크해 주세요.
그래도 안 되면 `pip` 대신 `python -m pip`, `streamlit` 대신 `python -m streamlit` 으로 실행해 보세요.
→ (Mac) `pip3`, `python3 -m pip`, `python3 -m streamlit` 처럼 뒤에 3을 붙여서 실행해 보세요.

**Q. "주가 데이터를 받아오지 못했습니다" 라고 나와요.**
→ 인터넷 연결을 확인하고 왼쪽 사이드바의 **데이터 새로고침** 버튼을 눌러 주세요.
회사·학교 네트워크는 야후 파이낸스 접속을 차단하는 경우가 있으니 다른 네트워크에서 시도해 보세요.

**Q. 특정 종목만 "제외되었습니다" 라고 나와요.**
→ 해당 종목의 데이터를 일시적으로 받지 못한 것입니다. 새로고침하면 대부분 해결됩니다.

**Q. 데이터는 실시간인가요?**
→ 야후 파이낸스 데이터는 15분 이상 지연될 수 있습니다. 대시보드는 1시간마다 자동으로
새 데이터를 받아오며, 사이드바의 새로고침 버튼으로 즉시 갱신할 수도 있습니다.

**Q. "진행 중인 이번 주 포함"이 무슨 뜻인가요?**
→ 주봉은 금요일에 완성됩니다. 체크하면 아직 진행 중인 이번 주 데이터까지 반영해서 판정하고,
체크를 풀면 완성된 지난주 금요일 종가 기준으로만 판정합니다.

**Q. (모바일) 앱이 안 열리고 "get this app back up" 화면이 나와요.**
→ 무료 클라우드 앱이 잠자기 모드로 들어간 것입니다. 버튼을 누르고 1분 정도 기다리면 다시 켜집니다.

**Q. (모바일) 화면이 좁아서 표가 잘려 보여요.**
→ 표를 손가락으로 좌우로 밀면 나머지 열이 보입니다. 폰을 가로로 돌리면 더 넓게 볼 수 있습니다.
