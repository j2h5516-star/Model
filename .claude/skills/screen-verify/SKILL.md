# 화면 ↔ 데이터 정합성 점검 (screen-verify)

저장소 주인 지시(2026-08-23): "화면과 데이터의 정합성을 계속 검증할 수
있도록 스킬을 만들고, 하루에 한 번 가동되게 시간을 지정해 작동시켜라."

## 왜 필요한가 — 전부 실제로 터진 일이다

시험은 **코드**를 지킨다. 그런데 사고는 전부 **"코드는 멀쩡한데 화면이
다른 말을 하거나 아무 말도 안 한 것"** 이었다:

| 회차 | 무슨 일이 있었나 |
|---|---|
| 150차-B | 웹앱이 제타를 "신호 아님"으로 표시 — 낡은 6월 완성이 8월 완성을 덮어씀 |
| 150차-C | "채택까지 얼마나 남았나"가 계기판에만 있고 웹앱엔 한 글자도 없음 |
| 150차-D | 같은 앱이 "정배열"을 두 뜻으로 쓰면서 그 말을 안 함 |
| 150차-F | 점검기와 앱이 "관찰판"을 다른 수로 셈 (89 vs 78) |
| 150차-J | 가설 11개가 전부 "표본 없음"이라고만 말함 |
| 150차-K | 주인이 "실적이 왜 빈칸이지?"라고 물어 꼬리 구멍 197건이 드러남 |

**여섯 건 중 다섯 건을 주인이 화면을 보다 발견했다.** 기계가 대신
봐야 한다.

## 절차

1. **웹앱 데이터를 먼저 새로 만든다** (옛 파일로 점검하면 무의미):
   ```
   find . -name __pycache__ -exec rm -rf {} +
   python3 web_build.py
   ```
   로봇이 방금 돌았으면 이 단계는 건너뛰어도 된다.

2. **점검을 돌린다** — 종료코드를 직접 확인한다:
   ```
   python3 screen_verify.py; echo $?
   ```

3. **출력 읽기**:
   - `⛔` — **화면이 데이터와 어긋난다. 즉시 고친다.** 종료코드 1.
   - `⚠️ 확인 못함` — 알려진 미해결(빠진 분기·끊김 너머 폭)이다.
     숫자가 **어제보다 늘었으면** 새로 생긴 것이니 파고든다.
   - 나머지 — 이상 없음.

4. **모바일에서 실제로 렌더링해 본다** (주인은 휴대폰만 쓴다):
   ```
   python3 -m http.server 8899 --directory docs &
   ```
   Playwright(크로미움 `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`,
   `--no-sandbox`)로 **412px** 에서 네 탭(`#/home` `#/market` `#/stocks`
   `#/check`)을 띄우고 확인한다:
   - `document.documentElement.scrollWidth == clientWidth` (가로 넘침 없음)
   - **요소마다** `getBoundingClientRect()` 로 412px 밖을 넘는 것이
     있는지 — 가로 스크롤만 보면 `overflow:hidden` 에 가려 놓친다
   - `pageerror` 콘솔 오류 0건
   끝나면 `pkill -f "http.server 8899"`.

5. **이상이 있으면** 측정결과.md 에 회차로 기록하고 고친다.
   이상이 없으면 **짧게 한 줄**만 보고한다 (주인은 비개발자 — 한국어로,
   코드 용어 풀어서).

## 무엇을 보는가 (12가지)

기준일 · 종목 수 · **신호 종목이 같은가** · **한 종목이 두 줄로 나오지
않는가** · 목록과 종목상세가 어긋나지 않는가 · 등록 가설이 전부 실렸는가 ·
**채택 거리(정직화 칸)가 빠지지 않았는가** · 두 '정배열' 잣대 차이 ·
빠진 분기 · 끊김 너머 신고점폭 · **분기 이름 어긋남**(150차-T) ·
판정 코드 버전.

## 주의

- 이 점검은 **읽기 전용**이다 — 어떤 값도 고치지 않는다.
- 화면에 **새 칸을 추가하면 여기에도 검사를 추가한다.** 안 그러면 그
  칸은 아무도 안 보는 칸이 된다(150차-C 가 그랬다).
- 검사를 새로 만들면 **일부러 깨뜨려 빨간 불을 본 뒤에만 믿는다**
  (`docs/data/app.json` 을 손으로 망가뜨려 ⛔ 가 뜨는지 확인하고 되돌린다).
  150차-N 에 여섯 가지 깨뜨림(신호 빼기·중복·기준일·가설 빼기·채택거리
  지우기·잣대차이 바꾸기)으로 전부 잡히는 것을 확인했다.
